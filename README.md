【项目简介】
把证书文件的 SHA-256 指纹写入区块链，核验时重新计算指纹与链上
记录比对：内容被改动哪怕一个字，指纹就完全不同，立即识破假证。
证书原文不上传，链上只存哈希，隐私安全。

【文件清单】
├── CertificateRegistry.sol   智能合约（签发 / 核验 / 撤销）
├── index.html                完整前端页面（四功能卡片 + 台账 + 日志）
├── ethers.umd.min.js         ethers.js v6.13.2 本地副本（离线也能跑）
├── 真证书.pdf                测试用真证书（张三，编号 CERT-2026-001）
├── 假证书.pdf                篡改样本（姓名被改为"张三丰"，指纹不同）
└── 提交说明.txt              本文件

【三行配置】index.html 顶部 "★★★ 只需修改这三行 ★★★" 处：
  1) RPC_URL          已预填 http://127.0.0.1:7545（Ganache QUICKSTART 默认端口）
  2) ADMIN_KEY        已预填 Ganache QUICKSTART 默认第一个账户私钥
                      （若你新建工作区时改过助记词，请换成你自己的）
  3) CONTRACT_ADDRESS 已预填 0xe78A0F7E598Cc8b0Bb87894B0F60dD2a88d6a8Ab
                      ——这是 QUICKSTART 环境按手册顺序"首次部署"得到的
                      固定地址。若页面提示合约不存在，把 Remix 左下角
                      Deployed Contracts 区显示的地址粘贴过来覆盖即可。

【快速开始】（详细图文见《操作手册》）
  ① 打开 Ganache → QUICKSTART（保持默认设置）
  ② 打开 remix.ethereum.org → 新建 CertificateRegistry.sol →
     粘贴本项目合约源码 → 编译器版本选 0.8.20 → Deploy（环境选
     Custom - External HTTP Provider，地址 http://127.0.0.1:7545）
  ③ 在项目文件夹打开命令行，执行:  python -m http.server 8000
  ④ 浏览器访问  http://localhost:8000/index.html
  ⑤ 右上角出现绿色"区块链已连接 · 合约就绪"即成功

【演示流程 · 3分钟版】
  1. 签发：编号 CERT-2026-001 + 真证书.pdf → 签发并写入区块链
     → 日志"✅ 上链成功！区块高度：2，Gas消耗：96625"，台账出现绿标
  2. 验真：同编号 + 真证书.pdf → 核验真伪 → 绿色"✅ 真实有效"
  3. 验假：同编号 + 假证书.pdf → 核验真伪 → 红色"❌ 内容被篡改"（高潮）
  4. 防重复：再次签发同一编号 → 友好提示 already issued
  5. 撤销：输入编号 → 撤销 → 台账变红色"已撤销"
  6. 复验：再验真证书 → 红色"❌ 已被颁发方撤销"
  每一步 Ganache 的 Transactions 区都有对应交易记录可对照。

【常见问题速查】
  · 右上角红色"无法连接节点" → Ganache 没开或端口不是 7545
  · "地址上没有合约代码"     → CONTRACT_ADDRESS 与实际部署不符，粘贴重填
  · 报 not admin            → 用的不是 Ganache 第一个账户的私钥
  · 报 invalid opcode       → Remix 编译器版本过新，改选 0.8.20 重编译
  · 页面空白                → 用 localhost 方式打开（第③步），不要双击 html
